本文档包含每个Boss的详细战斗机制设计。

## 通用Boss机制 / Common Boss Mechanics

### Boss战触发
- **触发条件**: 每5波结束时触发Boss战
- **场地清理**: Boss出现时，普通敌人停止刷新
- **Boss血条**: 屏幕顶部显示Boss名称和血条
- **背景音乐**: Boss战专属BGM
- **胜利条件**: 击败Boss后进入下一波

### Boss通用属性
| 属性 | 说明 |
|------|------|
| 免疫击退 | 所有Boss不受击退影响 |
| 免疫中毒 | 所有Boss不受毒药效果 |
| 伤害减免 | 所有Boss有20%基础伤害减免 |
| 碰撞伤害 | 接触玩家造成碰撞伤害 |

### Boss掉落奖励
| Boss | XP | 绿宝石 | 特殊掉落 | 实现状态 |
|------|-----|--------|----------|---------|
| Evoker | 50 | 30 | 不死图腾 (10%) | ✅ 已实现 |
| Elder Guardian | 80 | 50 | 海洋之心 (15%) | ⏳ |
| Ravager | 100 | 70 | 劫掠旗帜 (20%) | ⏳ |
| Warden | 150 | 100 | 幽匿碎片 (25%) | ⏳ |
| Wither | 200 | 150 | 下界之星 (30%) | ⏳ |
| Ender Dragon | 500 | 300 | 龙蛋 (100%) | ⏳ |

**已实现的掉落物:**
- `scripts/pickups/emerald_pickup.gd` - 绿宝石掉落
- `scripts/pickups/totem_pickup.gd` - 不死图腾掉落

### AI行为模式

```
状态机:
1. IDLE (空闲)
   - 与玩家保持200-250px距离
   - 如果太近，后退
   - 如果太远，靠近

2. CASTING_FANG (施放尖牙)
   - 停止移动
   - 播放施法动画
   - 释放尖牙攻击

3. SUMMONING (召唤恼鬼)
   - 停止移动
   - 播放召唤动画

优先级:
- 恼鬼数量 < 2 且 召唤冷却完成 → SUMMONING
- 尖牙冷却完成 → CASTING_FANG
- 否则 → IDLE (保持距离)
```

**单阶段Boss** - Evoker没有阶段变化，作为入门Boss保持简单。

### 战斗策略提示
- 优先击杀恼鬼，减少压力
- 注意地面紫色预警，及时侧移
- Evoker移动慢，可以绕后输出

## Wave 10: Elder Guardian 远古守卫者

### 基础属性

| 属性 | 数值 | 说明 |
|------|------|------|
| HP | 150 | 中等HP |
| 移动速度 | 30 | 非常慢，主要原地输出 |
| 碰撞伤害 | 10 | 中等接触伤害 |
| 尺寸 | 32×32px | 2倍玩家大小 |
| 荆棘反伤 | 5 | 近战攻击时反弹伤害 |

### 技能设计

#### 技能1: 激光攻击 (Laser Attack)
| 参数 | 数值 |
|------|------|
| 伤害 | 25 |
| 蓄力时间 | 2.0s |
| 冷却 | 4.0s |
| 射程 | 400px |

**机制:**
1. Guardian的眼睛锁定玩家，发出蓄力音效
2. 蓄力期间显示红色激光预警线(不造成伤害)
3. 预警线会持续追踪玩家位置
4. 2秒后激光发射，造成伤害
5. 激光发射瞬间位置固定(给玩家躲避机会)

**视觉效果:**
- 眼睛发光效果
- 红色虚线预警 → 实线激光
- 激光命中时屏幕闪烁

---

#### 技能2: 疲劳诅咒 (Mining Fatigue Curse)
| 参数 | 数值 |
|------|------|
| 减速效果 | -30% 移动速度 |
| 减攻效果 | -20% 攻击速度 |
| 持续时间 | 5.0s |
| 冷却 | 12.0s |
| 范围 | 全屏 |

**机制:**
1. Guardian身体膨胀，发出鬼脸图像
2. 全屏闪烁青色滤镜
3. 玩家获得疲劳Debuff
4. 屏幕边缘显示疲劳图标

**视觉效果:**
- Guardian鬼脸动画
- 屏幕青色闪烁
- 玩家周围显示减速粒子

---

#### 被动: 荆棘防御 (Spike Defense)
| 参数 | 数值 |
|------|------|
| 反伤 | 5点伤害 |
| 触发条件 | 玩家近战攻击时 |

**机制:**
- 每次玩家近战攻击Guardian时
- 玩家受到5点反伤
- 鼓励使用远程武器(弓箭)

---

### AI行为模式

```
状态机:
1. IDLE (空闲)
   - 缓慢向玩家移动
   - 保持100-150px距离

2. CHARGING_LASER (蓄力激光)
   - 停止移动
   - 眼睛追踪玩家
   - 显示预警线

3. FIRING_LASER (发射激光)
   - 固定激光方向
   - 造成伤害

4. CURSING (施放诅咒)
   - 停止移动
   - 播放鬼脸动画

优先级:
- 诅咒冷却完成 且 玩家距离 < 200px → CURSING
- 激光冷却完成 → CHARGING_LASER
- 否则 → IDLE
```

### 阶段设计

**HP < 50%: 狂暴阶段**
- 激光冷却减少至 3.0s
- 激光蓄力减少至 1.5s
- 眼睛变为红色

### 战斗策略提示
- 优先使用弓箭远程攻击，避免荆棘反伤
- 激光蓄力时注意预警线，最后一刻侧移
- 被诅咒后优先躲避，等Debuff结束

### AI行为模式

```
状态机:
1. WALKING (行走)
   - 向玩家移动
   - 移动速度50

2. CHARGING_UP (蓄力冲锋)
   - 停止移动
   - 锁定冲锋方向
   - 显示预警

3. CHARGING (冲锋中)
   - 高速向锁定方向移动
   - 造成碰撞伤害

4. STUNNED (硬直)
   - 冲锋后0.5s无法行动

5. STOMPING (践踏)
   - 停止移动
   - 播放践踏动画

6. ROARING (咆哮)
   - 停止移动
   - 播放咆哮动画

优先级:
- 玩家距离 < 60px 且 践踏冷却完成 → STOMPING
- 玩家距离 > 150px 且 冲锋冷却完成 → CHARGING_UP
- 受到累计伤害 > 50 且 咆哮冷却完成 → ROARING
- 否则 → WALKING
```

### 阶段设计

**HP < 40%: 狂暴阶段**
- 移动速度提升至 70
- 冲锋冷却减少至 3.5s
- 眼睛发红光
- 持续发出低吼声

### 战斗策略提示
- 看到红色箭头预警时立即侧移
- 冲锋后有硬直，趁机输出
- 保持中距离，避免践踏范围

### AI行为模式

```
状态机:
1. EMERGING (出现)

2. WALKING (行走)
   - 向玩家移动

3. CHARGING_SONIC (蓄力音波)
   - 停止移动
   - 胸口聚能
```

- 音波变为360度全向攻击
- 黑暗效果变为永久(直到Boss死亡或切换阶段)
- 玩家只能看到极小范围

### 战斗策略提示
- 音波无视护甲，必须躲避
- 黑暗期间注意Warden的蓝色脉冲位置
- 保持距离，避免重击范围

### AI行为模式

```
状态机:
1. HOVERING (悬浮)
   - 在玩家周围盘旋
   - 保持150-200px距离
   - 持续发射凋灵头颅

2. CHARGING_BLUE (蓄力蓝头颅)
   - 短暂停止移动
   - 中央头颅发光

   - 三个头颅同时发光
   - 生成凋灵骷髅

4. SHIELD_PHASE (护盾阶段)
   - HP < 50% 触发
   - 获得护盾，只受近战伤害

优先级:
- HP < 50% 且 未进入护盾阶段 → SHIELD_PHASE
- 召唤冷却完成 且 场上骷髅 < 2 → SUMMONING
- 蓝头颅冷却完成 → CHARGING_BLUE
- 否则 → HOVERING (持续发射普通头颅)
```

### 阶段设计

**阶段1: 正常阶段 (HP 100%-50%)**
- 正常攻击模式
- 三个头颅轮流攻击

**阶段2: 护盾阶段 (HP 50%-0%)**
- 获得蓝色护盾
- **免疫所有远程伤害**
- 只受近战攻击伤害
- 头颅攻击频率提升
- 蓝色头颅冷却减少至 5s
- 玩家必须近战输出

### AI行为模式

```
状态机:
1. FLYING (盘旋)
   - 在场地上空盘旋
   - 绕圈飞行

2. BREATH_ATTACK (龙息)
   - 俯冲到场地中央
   - 释放龙息云
   - 返回空中

3. DIVING (俯冲)
   - 飞到场地边缘
   - 高速穿过场地

4. SUMMONING (召唤)
   - 悬停
   - 召唤末影人

5. CRYSTAL_PHASE (水晶阶段)
   - 召唤水晶
   - 躲在水晶保护下

6. STORM_PHASE (风暴阶段)
   - 飞到最高点
   - 释放末影风暴
```

### 阶段设计

**阶段1: 天空之王 (HP 100%-60%)**
- 主要在空中盘旋
- 使用龙息、俯冲、召唤末影人
- 攻击间隔较长，让玩家熟悉模式

**阶段2: 水晶守护 (HP 60%-30%)**
- 召唤末影水晶
- 水晶存在时，末影龙受伤减半
- 俯冲频率增加
- 龙息释放2个云

**阶段3: 终末之怒 (HP 30%-0%)**
- 解锁末影风暴技能
- 持续召唤末影人
- 攻击间隔大幅缩短
- 龙身体发出紫色光芒
- 俯冲变为连续2次

### 战斗策略提示
- 第一阶段熟悉攻击模式
- 第二阶段优先摧毁水晶
- 第三阶段风暴时跑到中央
- 全程注意躲避龙息区域
- 击杀末影人获得喘息机会
